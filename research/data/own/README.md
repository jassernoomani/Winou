# Own photos

One folder per individual animal, at least 3 photos each, ideally taken from
different angles, distances and lighting:

```
own/
├── cat_mimi/
│   ├── 01.jpg
│   ├── 02.jpg
│   └── 03.jpg
└── dog_rex/
    └── ...
```

Prefix the folder with `cat_` or `dog_` so the species is known. These photos
are git-ignored and never leave your machine.
